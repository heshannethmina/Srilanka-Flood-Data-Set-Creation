# Figure data and provenance

The figures use measured coordinates, catalogue entries and recorded experiment
summaries. They do not contain simulated predictions, invented uncertainty
intervals or reconstructed hydrographs.

| Input | Provenance | Scope |
|---|---|---|
| `model2_recorded_results.csv` | Transcribed from `docs/RESULTS.md`, model-2 rows from 10–11 August 2026 | Hand-compiled historical summary; prediction arrays are unavailable. Blank values are unavailable, not zero. |
| `../../data/processed/nodes.csv` | Project node inventory | 51 modelling locations, 16 basin/area groups; zone labels are inventory categories. |
| `../../data/processed/edges.csv` | Project curated connectivity | 35 flow links, 204 spatial links. The map draws only flow links as straight connections. |
| `../../data/processed/events.csv` | Discharge-threshold episode catalogue | 1,469 node-level episodes through 2025; 1,464 start during 2003–2024. These are not independent disaster events or model-evaluable episode counts. |
| `sri_lanka_outline.geojson` | Natural Earth, 1:50m Admin 0 Countries, Sri Lanka feature | Country outline only; no hydrological basin boundaries. Retrieved 8 September 2026. |
| `catalogue_counts.json` | Generated by `make_figures.py` | Annual catalogue onset counts and date-filter audit. |

Natural Earth source:
[maintainer's GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_admin_0_countries.geojson).
The country feature was extracted without changing its coordinates.
[Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/)
describe the dataset as public domain.

Main-result AP is the repository's stored `pr_auc`, calculated by its stepwise
average-precision routine. The manuscript explains its treatment of ties.
Parameter values are the recorded counts per member, not total ensemble size,
FLOPs, inference time or a guaranteed count of all frozen parameters.

The previous seed-noise and leakage figures are retained only in the original
archive. Test node-day AP differences cannot be compared with a validation
episode-AP range as a significance test. Randomly sampled test rows also change
the availability of pre-onset observations, so the original causal leakage
interpretation was removed.

Before substituting new results, retain the panel checksum, run configuration,
cutoff policy, selected checkpoint, threshold, temperature, full prediction
arrays and metric implementation version. Replace this CSV with values from
those artifacts and regenerate both figures and manuscript tables.
